Transaction ledger

Immutable. Every stock change writes exactly one row, and rows are never updated or deleted — enforced by database triggers.

Putaway planner

Answers where a quantity of an item should go and how many units belong in each location. Eligibility uses the same hard rules putaway itself enforces — hazardous goods, storage temperature, category and mixing — so a plan can never suggest a location the putaway would refuse. The order among eligible locations is a preference, and every line says why it ranked where it did.
